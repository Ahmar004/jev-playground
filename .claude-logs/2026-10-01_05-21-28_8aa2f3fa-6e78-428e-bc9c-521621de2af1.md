Yes. Remote Control works when your phone is on a different Wi-Fi, or on mobile data, anywhere. Your computer never accepts incoming connections; it makes outbound HTTPS requests to Anthropic's servers only, and your phone connects to those same servers. No port forwarding and no shared network needed.

**How to enable it**

1. In this Claude Code terminal, type **`/remote-control`** (short form: **`/rc`**). You can add a name, for example `/remote-control Jev's Playground`.
2. The first time, a confirmation dialog appears. Select **Enable Remote Control**.
3. An `/rc active` indicator appears in the terminal. Run `/remote-control` again to see the session link and a **QR code**.
4. On your phone, either scan the QR code, or open the **Claude app**, tap **Code**, and pick the session. It shows a computer icon with a green dot while online. Any browser works too, at claude.ai/code.

To have every new session start with Remote Control on, run `/config` and set **Enable Remote Control for all sessions**.

**Requirements**
- A Pro, Max, Team or Enterprise plan, signed in to Claude Code through claude.ai (`/login`). API-key logins don't support it.
- The Claude app on your phone, signed in to the **same account**.

**What has to stay true on your computer**
- **It stays on and awake.** If it sleeps, the session goes offline and reconnects by itself when it wakes. For long stretches away, set Windows to never sleep while plugged in (Settings > System > Power).
- **The terminal running `claude` stays open.** Closing it takes the session offline. Reopen it with `claude --continue`, then run `/remote-control` again.
- **The computer stays online.** Your phone's network doesn't matter, but the computer needs internet.

**Good to know**
- Code still runs only on your computer, with your files, `.env.local` and tools. The phone is a window into that session.
- While it's on, the conversation is stored on Anthropic's servers to keep your devices in sync.
- For extra security, you can turn on **Require trusted devices** in claude.ai > Settings > Account. Then only devices you've verified can control the session.
- Optional: in `/config`, turn on **Push when actions required** to get a phone notification whenever Claude needs your approval or an answer.

Per Rule-6, the best moment is when you start the next session for Step-6: run `/remote-control` right at the start, and you can follow and answer from your phone.
