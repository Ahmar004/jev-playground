## 1. Does Claude Pro include API access?

No. Claude Pro (claude.ai and Claude Code) and the Claude API are billed separately. Pro covers chatting on claude.ai and using Claude Code. It does not give you an API key or any API credit. Our recording CLI calls the API directly with an `ANTHROPIC_API_KEY`, so it needs prepaid API credit from the Claude Console.

**How to get the key:**
1. Go to https://platform.claude.com and sign in. You can use the same email as claude.ai, but it's a separate billing account.
2. Go to **Settings > Billing** and buy credits. API credit is prepaid, so you add a card and top up.
3. Go to **Settings > API keys > Create key**, name it something like `jevs-playground-recording`, and copy it. It's shown only once.
4. Optional but sensible: under **Settings > Limits**, set a monthly spend limit and leave auto-reload off. That makes it impossible to overspend.

## How to use it

## Why it fits this project badly right now

1. **Unpushed work.** A cloud session clones from GitHub. Slices 3 and 4 have about 20 local commits that aren't pushed, plus uncommitted files such as the Speed Race task and the level route. A cloud session wouldn't see any of them.
2. **Session logs.** `.claude-logs/` capture comes from hooks in your local `~/.claude/settings.json`. A cloud session doesn't run them, so it would produce no log, and CLAUDE.md requires a log for every change.
