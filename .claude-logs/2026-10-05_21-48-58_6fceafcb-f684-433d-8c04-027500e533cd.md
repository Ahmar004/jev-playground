The app calls them "VS games" because each one is a head-to-head race, with Jev on one side and an LLM on the other. Plain "games" would not say that.

- **Definition:** `spec.md` section 1.2 defines a VS game as "an animated race where Jev and an LLM do the same job."
- **Format:** Section 7.1 says every game has two racers, Jev and one LLM, doing the same job on the same inputs. The user watches them compete on a live scoreboard of accuracy, time and cost, and the game ends with a winner and a reveal.
- **Naming rule:** `CLAUDE.md` says to use the spec 1.2 vocabulary and "don't invent synonyms."
- **Other game-like features:** Speed Race, the Arena (a side-by-side comparison) and the Sandbox are all separate features in the spec. Calling these "VS games" keeps them from being confused with those.
- **Timed games:** The leaderboard section also lists "all VS games and Speed Race" separately, so Speed Race is not counted as a VS game.

I did not find a recorded reason for the name beyond the definition and the format, so the "VS" is most likely just short for "versus."
